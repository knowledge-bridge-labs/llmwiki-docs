# Code of Conduct

LLM Wiki Toolchain Docs is intended to be a practical, respectful open-source
documentation project. Contributors and maintainers are expected to keep
discussions focused on the software, documentation, and people using it.

## Expected Behavior

- Be respectful and constructive in issues, pull requests, reviews, and chat.
- Keep feedback specific to the work.
- Respect privacy and do not publish credentials, private endpoint details,
  raw wiki content, runtime logs, screenshots, or sensitive data.
- Keep review comments actionable and tied to documentation correctness,
  compatibility, security, accessibility, or maintainability.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Posting credentials, tokens, private endpoint details, private wiki exports,
  raw runtime logs, or sensitive data.
- Misrepresenting validation results, protocol conformance, or security impact.

## Reporting and Enforcement

Report conduct concerns through the private maintainer or organization contact
published for this repository. If no private contact is listed yet, open a
public issue only to request a private conduct contact path, then stop. Do not
include incident details, private data, credentials, or screenshots in that
public request. Do not open a public pull request or discussion for conduct
reports. For suspected security vulnerabilities, use the process in
`SECURITY.md` instead.

Maintainers may edit, hide, or remove comments, close issues, reject pull
requests, request changes, or temporarily restrict participation when behavior
harms the project or its contributors.
