# Support

Use public issues for reproducible documentation gaps, broken links, unclear
setup steps, or missing integration guidance.

Use the affected code repository when the question is specific to:

- `llmwiki-serve` server behavior
- `llmwiki-agent-bridge` runtime profiles or bridge behavior
- `llmwiki-chat` UI, adapters, or browser workflows

Do not post private endpoints, tokens, raw wiki exports, runtime logs, or
screenshots that reveal private infrastructure.

For suspected vulnerabilities, do not open a public issue. Follow
[SECURITY.md](SECURITY.md).
