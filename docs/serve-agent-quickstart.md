# QuickStart Compatibility Alias

This route is kept so existing external links to `/serve-agent-quickstart` do
not 404.

The canonical package-first tutorial is now [QuickStart](/quickstart). It
starts with `llmwiki-serve`, verifies the source layer, and then adds
`llmwiki-bridge-start` as the next handoff step.

No duplicate tutorial content is maintained on this compatibility page.
